# HIDE PUZZLE

置いたピースの輪郭がグリッドへ溶け込み、見えなくなる記憶型パズルゲームです。

## 遊び方

`index.html` をブラウザで開き、ホーム画面で4×4〜9×9の開始サイズを選んで`PLAY`を押してください。選択しなければ4×4から始まり、クリアするたびに縦横が1マスずつ増えます。各ピースの面積は、そのレベルの盤の縦マス数以下です。盤外や別のピースと重なる位置ではピースが元の場所へ戻り、配置済みピースをクリックすると取り外せます。

## GitHub Pages で公開

1. このフォルダの `index.html`、`README.md`、`.nojekyll` をGitHubリポジトリへプッシュします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、`main` / `/(root)` を指定して保存します。

外部ライブラリやビルド作業は不要です。
